🌿 Green Flames
O Green Flames é uma plataforma web desenvolvida para conscientização, prevenção e combate às queimadas e incêndios ambientais. O projeto reúne informações, notícias, serviços, orientações e um sistema de denúncias, incentivando a participação da comunidade na proteção do meio ambiente.

✨ Funcionalidades
🏠 Página inicial informativa
📰 Seção de notícias
🚨 Sistema de denúncias
🛠️ Página de serviços
📞 Página de contato
🔐 Tela de login
🔑 Recuperação de senha
📱 Interface responsiva
🛠️ Tecnologias Utilizadas
HTML5
CSS3
JavaScript
Design Responsivo
🎯 Objetivo
Promover a conscientização ambiental e facilitar o acesso da população a informações e ferramentas para denunciar queimadas, contribuindo para a preservação do meio ambiente.

Desenvolvido como projeto acadêmico e de conscientização ambiental.
